# iOS 声音警报（轻量版）

> **不录音、不做 AI、不耗电**
>
> 直接利用 iPhone 系统自带的声音识别，通过快捷指令触发通知，智能指环自动震动。

---

## 💡 核心思路

```
iPhone 系统声音识别（辅助功能）
            ↓ 检测到声音
    iOS 快捷指令（Shortcuts）自动化
            ↓ 触发
    本 App 的 App Intent（发送声音警报）
            ↓ 发送本地通知
    智能指环（ANCS 蓝牙协议）
            ↓ 接收到通知
        指环震动！
```

**本 App 的角色**：作为系统声音识别和指环之间的"通知中转站"

---

## 🆚 与完整版的区别

| 对比 | 完整版 `AudioClassifier` | 轻量版 `AudioDetectLight` |
|------|-------------------------|--------------------------|
| 声音识别 | App 自己录音 + AI 模型 | **系统辅助功能** |
| 麦克风权限 | 需要 | **不需要** |
| 后台运行 | 持续录音，耗电高 | **只在被调用时运行 0.1 秒** |
| 耗电量 | 每小时 5-10% | **几乎为 0** |
| 识别准确率 | 取决于训练模型 | **Apple 官方优化** |
| 可识别类别 | 6 类（自定义） | 12+ 类（Apple 预设） |
| 需要快捷指令 | 不需要 | **需要配置** |
| 需要 Mac 开发 | 是 | 是 |

## 📱 使用步骤（用户端）

### 第一步：安装 App

- 用 Xcode 编译安装到 iPhone（需要 Mac）
- 或通过 TestFlight 分发（需要 Apple Developer 账号）

### 第二步：开启系统声音识别

1. 打开 iPhone `设置`
2. 进入 `辅助功能 → 声音识别`
3. 打开开关
4. 在"声音"列表中勾选你想监听的声音（如婴儿啼哭、敲门声）

### 第三步：配置指环通知

1. 打开你的智能指环配套 App（如 RingConn）
2. 找到 `消息提醒 / Notifications`
3. 开启 `系统通知` 或 `其他应用通知`

### 第四步：配置快捷指令（最关键）

1. 打开 iPhone `快捷指令` App
2. 点击底部 `自动化` 标签
3. 点击右上角 `+`
4. 创建 `个人自动化`
5. 向下滚动，找到 `声音识别`，点击进入
6. 选择你想监听的声音（如"婴儿啼哭"）
7. 点击 `下一步`
8. 点击 `添加动作`
9. 搜索 `声音警报` 或 `AudioDetect`
10. 找到 `发送声音警报`，点击添加
11. 配置参数：
    - 声音类别：选择对应的声音
    - 震动强度：选择"中"或"强"
    - 重复次数：一般设为 1
12. 关闭 `运行前询问`（这样触发后自动执行，不需要确认）
13. 点击 `完成`

**重复步骤 4-13**，为每种你想监听的声音都创建一个自动化。

### 第五步：测试

1. 在 App 中点击 `测试发送` 区域的按钮（如敲门声）
2. 看指环是否震动
3. 如果震动，说明配置成功
4. 然后可以触发真实的声音（如敲门）测试整个流程

## 🔧 编译步骤

### 1. 创建 Xcode 项目

```bash
cd ios_lightweight

# 或者直接用 Xcode 创建：
# File → New → Project → iOS App
# 名称：AudioDetectLight
# 界面：SwiftUI
# 语言：Swift
# 最小版本：iOS 16.0
```

### 2. 添加文件

将 `AudioDetectLight/` 目录下的所有 Swift 文件拖到 Xcode 项目中。

### 3. 添加依赖框架

在 Xcode 中：
1. 选中项目 → Target → **AudioDetectLight**
2. 点击 **Frameworks, Libraries, and Embedded Content**
3. 点击 `+` 添加：
   - `AppIntents.framework`
   - `UserNotifications.framework`

### 4. 编译运行

1. 连接 iPhone 或选择模拟器
2. 点击 ▶ Run 按钮
3. 首次运行会请求通知权限，点击允许

## ⚠️ 限制

1. **需要 iOS 16+**：`AppIntent` 框架要求 iOS 16 或更高版本
2. **需要手动配置快捷指令**：每个声音类别都需要单独创建自动化，不能一键配置
3. **后台限制**：App 本身不运行，但快捷指令在后台执行时可能受 iOS 限制（系统声音识别触发时，快捷指令会自动唤醒）
4. **指环兼容性**：取决于指环配套 App 是否支持 ANCS 协议
5. **延迟**：系统声音识别（0.5s）+ 快捷指令执行（0.3s）+ 蓝牙通知（0.2s）≈ 1 秒总延迟

## ❓ 常见问题

**Q: 为什么 App 自己不做声音识别？**  
A: iPhone 系统的声音识别已经由 Apple 优化，准确率高且省电。我们直接利用它，不需要自己开发 AI 模型。

**Q: 快捷指令配置太麻烦？**  
A: 这是目前 iOS 的**唯一合法途径**。第三方 App 无法直接监听系统声音识别的结果。配置一次后，后续自动运行，不需要再操作。

**Q: 指环没有震动？**  
A: 按以下顺序排查：
1. 在 App 中点击"测试发送"，看 iPhone 是否弹出通知
2. 如果 iPhone 有通知但指环没震动，检查指环 App 的通知权限
3. 如果 iPhone 没有通知，检查快捷指令配置是否正确

**Q: 耗电吗？**  
A: **几乎不耗电**。App 本身完全不运行，只在快捷指令调用时短暂启动（约 0.1 秒），发送通知后立即退出。耗电主要来自系统声音识别（系统级优化，功耗很低）。

**Q: 没有 Mac 怎么编译？**  
A: iOS App 必须 macOS + Xcode 编译。没有 Mac 的话，可以：
1. 找朋友借 Mac 编译
2. 用 GitHub Actions 的 macOS runner（但只能编译，无法直接安装到真机）
3. 考虑用之前完成的 Android 离线 APK 方案（Windows 可用）
